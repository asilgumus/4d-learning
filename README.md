# 4D Learning Platform

An English, dependency-free library of reusable STEM project guides from FRC Team 6429, 4th Dimension.

## Run locally

```sh
npm run dev
```

Open `http://localhost:4173`. Run `npm run check` to validate JavaScript, content records and local resource files.

## Add the upcoming presentations

The cybersecurity presentation has been added. Place the technology-addiction source file in `assets/resources/`, then update its record in `data.js`: change `status` to `available` and add guide `sections` using the same structure as the active projects.
