Light-Following Robot

Intermediate · 90 min · Differential control

Compare two light sensors and steer a two-motor robot toward the brighter side.

Malzemeler

  • Arduino Uno
  • 2 LDRs
  • 2 × 10 kΩ resistors
  • L298N motor driver
  • 2 DC gear motors and chassis
  • Motor battery pack

Bağlantı

  1. Build two 5V LDR voltage dividers and connect their centres to A0 and A1.
  2. Connect L298N IN1–IN4 to pins 4–7; keep ENA/ENB jumpers installed.
  3. Power motors externally and join driver and Arduino grounds.

Kod

const int leftLdr=A0, rightLdr=A1;
const int in1=4, in2=5, in3=6, in4=7;

void motors(bool lf, bool lb, bool rf, bool rb) {
  digitalWrite(in1,lf); digitalWrite(in2,lb);
  digitalWrite(in3,rf); digitalWrite(in4,rb);
}
void setup() {
  pinMode(in1,OUTPUT); pinMode(in2,OUTPUT); pinMode(in3,OUTPUT); pinMode(in4,OUTPUT);
}
void loop() {
  int left=analogRead(leftLdr), right=analogRead(rightLdr);
  int difference=left-right;
  if (abs(difference)<50) motors(HIGH,LOW,HIGH,LOW);
  else if (difference>0) motors(LOW,LOW,HIGH,LOW);
  else motors(HIGH,LOW,LOW,LOW);
}

Ne olmalı?

The robot moves forward under balanced light and turns toward the brighter sensor.

Meydan okuma

Calibrate the dead-band and shield the two LDRs from each other.

Güvenlik ve sorun giderme

  • Bağlantıyı değiştirmeden önce gücü kes.
  • Her LED ile direnç kullan.
  • Kart ve port seçimini Arduino IDE'de kontrol et.
  • Her kablonun koddaki pin numarasıyla eşleştiğini doğrula.
