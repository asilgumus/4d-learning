Arduino experiment 17

Automatic Fan Controller

Intermediate · 65 min · Threshold control

Switch a small DC fan on automatically when a DHT11 reports high temperature.

Materials

  • Arduino Uno
  • DHT11 module
  • Logic-level N-channel MOSFET
  • Small DC fan
  • Flyback diode
  • 10 kΩ gate pull-down
  • External fan supply

Wiring

  1. Connect DHT11 DATA to pin 4.
  2. Drive the MOSFET gate from pin 6; add 10 kΩ from gate to GND.
  3. Connect fan through the MOSFET and external supply; place the diode reverse-biased across the fan.
  4. Join external supply and Arduino grounds.

Code

#include <DHT.h>
#define DHTPIN 4
#define DHTTYPE DHT11
DHT dht(DHTPIN, DHTTYPE);
const int fanPin = 6;
const float threshold = 28.0;

void setup() { pinMode(fanPin, OUTPUT); dht.begin(); }

void loop() {
  float temperature = dht.readTemperature();
  if (!isnan(temperature)) digitalWrite(fanPin, temperature >= threshold);
  delay(2000);
}

What should happen?

The fan starts at or above 28 °C and stops below it.

Challenge

Add a second, lower off-threshold to prevent rapid switching.

Safety and troubleshooting

  • Cut the power before changing the wiring.
  • Use a resistor with every LED.
  • Check the board and port selection in the Arduino IDE.
  • Check that every wire matches the pin number in the code.
