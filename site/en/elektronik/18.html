Arduino experiment 18

PIR Motion Alarm

Intermediate · 45 min · Motion sensing

Detect movement with a PIR sensor and trigger a small buzzer or LED.

Materials

  • Arduino Uno
  • PIR motion sensor
  • Active 5V buzzer or LED with 220 Ω resistor
  • Jumper wires

Wiring

  1. Connect PIR VCC to 5V, GND to GND and OUT to pin 2.
  2. Connect a low-current active buzzer to pin 8 and GND, or use an LED with a resistor.

Code

const int pirPin = 2, alarmPin = 8;

void setup() {
  pinMode(pirPin, INPUT); pinMode(alarmPin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  bool motion = digitalRead(pirPin);
  digitalWrite(alarmPin, motion);
  if (motion) Serial.println("Motion detected");
  delay(100);
}

What should happen?

After its warm-up period, the PIR activates the output when movement is detected.

Challenge

Keep the alarm active for five seconds after the last movement.

Safety and troubleshooting

  • Cut the power before changing the wiring.
  • Use a resistor with every LED.
  • Check the board and port selection in the Arduino IDE.
  • Check that every wire matches the pin number in the code.
