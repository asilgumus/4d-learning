Arduino experiment 08

Mini Emergency Light

Beginner · 30 min · Timed outputs

Alternate two coloured LEDs to create a compact warning-light pattern.

Materials

  • Arduino Uno
  • Red and blue LEDs
  • 2 × 220 Ω resistors
  • Breadboard and jumper wires

Wiring

  1. Connect pins 8 and 9 through separate 220 Ω resistors to the LED anodes.
  2. Connect both cathodes to GND.

Code

const int ledA = 8, ledB = 9;

void setup() {
  pinMode(ledA, OUTPUT); pinMode(ledB, OUTPUT);
}

void loop() {
  digitalWrite(ledA, HIGH); digitalWrite(ledB, LOW); delay(150);
  digitalWrite(ledA, LOW); digitalWrite(ledB, HIGH); delay(150);
}

What should happen?

The two LEDs flash alternately.

Challenge

Design a double-flash pattern using a helper function.

Safety and troubleshooting

  • Cut the power before changing the wiring.
  • Use a resistor with every LED.
  • Check the board and port selection in the Arduino IDE.
  • Check that every wire matches the pin number in the code.
