Arduino experiment 09

Clap-Triggered Light

Beginner · 45 min · Event detection

Detect a clap or other sharp sound and light an LED briefly.

Materials

  • Arduino Uno
  • Digital microphone/sound module
  • LED
  • 220 Ω resistor
  • Breadboard and jumper wires

Wiring

  1. Connect module VCC to 5V, GND to GND and OUT to pin 2.
  2. Connect pin 13 through 220 Ω to the LED anode and its cathode to GND.

Code

const int micPin = 2, ledPin = 13;
unsigned long lastTrigger = 0;

void setup() {
  pinMode(micPin, INPUT); pinMode(ledPin, OUTPUT);
}

void loop() {
  if (digitalRead(micPin) == HIGH && millis() - lastTrigger > 300) {
    digitalWrite(ledPin, HIGH);
    delay(200);
    digitalWrite(ledPin, LOW);
    lastTrigger = millis();
  }
}

What should happen?

A sharp sound produces one controlled flash instead of repeated triggers.

Challenge

Count claps and switch the LED state after two detections.

Safety and troubleshooting

  • Cut the power before changing the wiring.
  • Use a resistor with every LED.
  • Check the board and port selection in the Arduino IDE.
  • Check that every wire matches the pin number in the code.
