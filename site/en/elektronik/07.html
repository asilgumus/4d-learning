Arduino experiment 07

Moving Flag with a Servo

Beginner · 45 min · Servo control

Move a lightweight paper flag between three angles with an SG90 servo.

Materials

  • Arduino Uno
  • SG90 micro servo
  • Lightweight paper flag
  • Jumper wires
  • External regulated 5V supply recommended

Wiring

  1. Connect servo signal to pin 9.
  2. Connect servo power to regulated 5V and ground to GND.
  3. If using an external supply, connect its GND to Arduino GND.

Code

#include <Servo.h>
Servo flagServo;

void setup() {
  flagServo.attach(9);
}

void loop() {
  flagServo.write(0); delay(1000);
  flagServo.write(90); delay(1000);
  flagServo.write(180); delay(1000);
}

What should happen?

The servo moves the flag between 0°, 90° and 180°.

Challenge

Use a for loop to make the motion smooth.

Safety and troubleshooting

  • Cut the power before changing the wiring.
  • Use a resistor with every LED.
  • Check the board and port selection in the Arduino IDE.
  • Check that every wire matches the pin number in the code.
