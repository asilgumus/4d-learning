CAD, Electronics, Software

Three curricula: 3D design with CAD (6 lessons), electronics with Arduino (19 experiments, code and a Turkish worksheet) and software with Python (6 lessons). Every lesson has steps and a hands-on task.

Middle schoolHigh school15–25 min per lesson

Curricula

CAD: 3D design

Design the part you imagine on the computer and print it on a 3D printer. You need: Onshape (free, in the browser).

1. Interface and first sketchVideo

Plane, sketch, dimensioning

  1. Create a free (education) account at onshape.com.
  2. Create a new Document and open the Part Studio.
  3. Select the Front plane and start the Sketch tool.
  4. Draw a rectangle and set 40×20 mm with Dimension.

Task: Sketch the first letter of your name and dimension it.

2. Extrude and cutVideo

From a 2D sketch to a 3D body

  1. Finish the sketch (green check).
  2. Extrude it to a height of 10 mm.
  3. Sketch on another face and cut a pocket with Extrude's Remove option.

Task: Design a keychain body: 60×30×5 mm with a hole in the middle.

3. Holes and chamfersVideo

Screw hole, fillet, chamfer

  1. Draw a circle sketch for a cylindrical hole.
  2. Cut an M3 screw hole (3.2 mm) with Extrude Remove.
  3. Apply a Fillet (2 mm) to sharp corners and a Chamfer to the edge.

Task: Add 4 corner holes and rounded corners to your part.

4. AssemblyVideo

Joining parts and mates

  1. Open a new Assembly.
  2. Import the parts.
  3. Connect them with Fastened and Revolute mates.
  4. Test the motion.

Task: Design a two-part hinge and rotate it with mates.

5. Technical drawingVideo

Three views and dimensioning

  1. Create a Drawing from the Part.
  2. Add front, top and side views.
  3. Add dimensions and fill in the scale and title block.
  4. Export as PDF.

Task: Make a technical drawing of your keychain and print it.

6. Preparing for the 3D printerVideo

STL export, slicing settings

  1. Right-click the Part, Export, format STL, unit millimetres.
  2. Open it in a slicer (Cura/PrusaSlicer).
  3. Layer 0.2 mm, infill 20%, supports if needed.
  4. Read the print time and weight.

Task: Print your part and compare the measurements with the design using calipers.

Software: from Python to a robot

Think algorithmically and carry your program over to a robot. You need: Python 3, Thonny, Arduino IDE.

1. Variables and printing to the screenVideo

print, input, data types

  1. Install and open Thonny.
  2. Type print("Hello") and run it.
  3. Read user input with name = input("Your name? ").
  4. Try variables and data types (int, str, float).

Task: Write a program that asks for a name and age and says 'X, next year you will be Y'.

2. Making decisionsVideo

if / else and comparison

  1. Write the if / elif / else structure.
  2. Comparison operators: ==, !=, <, >.
  3. Give a 'higher/lower' hint in a number guessing game.

Task: Write a program that converts a score into a letter grade.

3. LoopsVideo

for, while and patterns

  1. Count with for i in range(5):.
  2. Build an 'ask until the right answer' loop with while.
  3. Draw a star triangle with a nested loop.

Task: Print the numbers from 1 to 100 that are divisible by 3.

4. FunctionsVideo

Splitting code into pieces

  1. Define a function with def.
  2. Use parameters and return.
  3. Move repeated code into a function.

Task: Write a function that calculates the area of a circle and returns the result.

5. Lists and dictionariesVideo

Collecting data

  1. Create a list, use append and len.
  2. Store key-value pairs with a dictionary (dict).
  3. Loop over a list with for.

Task: Find the average and the tallest from a list of your classmates' heights.

6. Introduction to robotsVideo

A bridge from Python to Arduino and robot coding

  1. Send commands from Python to Arduino over the serial port (pyserial).
  2. Receive the command on the Arduino side with Serial.read().
  3. Light the LED when '1' arrives and turn it off on '0'.

Task: Light different LEDs depending on the letter you send from the keyboard.
